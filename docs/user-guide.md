# ReportPilot 普通用户手册

> 适用角色：**普通用户**（顶栏右上角显示「普通用户」）。
> 全程约 5 分钟。你实际只需要做两件事：**建一个报告任务**、**在收到邮件后确认一次**。
> 中间的取数、汇算、写稿、排版、发送、催办，全部由系统自动完成。

---

## 0. 权限速查

| 你 **可以** | 你 **不可以**（需要管理员或模板属主） |
|---|---|
| 新建 / 编辑 / 删除**自己创建**的指标 | 改别人创建的指标 |
| 上传模板、给模板配绑定（自己的模板，或被授权「编辑」的模板） | 删除模板、把模板授权给别人（仅属主 / 管理员） |
| 创建 / 编辑 / 停用 / 删除报告任务，**手动触发**一次 | 改 SMTP、AI 接口、AD、全局提示词（系统设置 → 运行时配置） |
| 确认报告、重新生成某段 AI 摘要、查看 AI 调用留痕 | 「代确认并发送」（管理员特权） |
| 查看「系统设置 → 用户」列表（只读） | 新建 / 编辑 / 停用用户 |
| —— | 查看推送记录（系统设置 → 推送记录） |
| —— | 维护数据源（数据源管理页对普通用户只读） |

## 1. 登录

浏览器打开系统地址 → 输入**用户名**和**密码** → 点「登录」。

登录后顶栏显示：系统导航 + 你的姓名 + 「普通用户」标签 + 「退出登录」。

---

## 2. 准备两样东西：指标 + 模板

### 2.1 新建指标（指标管理 → 新增指标）

选指标类型 → 选数据源与监控项 → 设聚合方式与周期 → 点「**试算**」先看结果 → 保存。

- 常用类型：数值（scalar）、折线（curve）、饼图（pie）、文本（text）、时间（time）、计算式（calculated）。
- 列表里「编辑」「删除」只对自己的指标出现；「**试算**」人人可用。
- 指标是模板变量的一种来源（另一种是 AI 摘要，由系统写文字）。

### 2.2 上传模板（模板管理 → 上传模板）

1. 填「**名称**」→ 「**选择文件**」（仅 `.docx`，≤ 10MB）→「**确定**」。
2. 弹窗显示「**已解析变量（N）**」→ 「**完成并关闭**」。
3. 在 Word 里用 `{{ 变量名 }}` 占位；**图表变量必须独占一个段落**（混排保存时会被拒绝）。
4. ⚠️ 模板名是**全系统唯一**的，重名会报「模板名称已存在」。

### 2.3 配置绑定（模板管理 → 该模板「配置绑定」）

每个变量选一种类型：

| 类型 | 填什么 |
|---|---|
| **指标** | 选一个指标；可再设单位、显示精度、数值变换 |
| **AI 摘要** | 点「**配置提示词 / 范文**」写「写作要求」和「参考范文」，可先「**试跑**」看效果；还能调字数上限、温度、波动阈值 |

点「**保存绑定**」后生效。

> AI 摘要的写法按**段落**配置；全局写作规则由管理员维护，你不用管。

## 3. 创建报告任务（报告任务 → 新建任务）

| 字段 | 填什么 |
|---|---|
| **任务名称** | 如「每月运维月报」 |
| **模板** | 选一个已启用、且你能看到的模板 |
| **周期规则** | 选「常用预设」，或直接填 5 段 cron（分 时 日 月 周，如 `0 9 1 * *`）；下方会显示「下次执行 …」，写错会红字提示 |
| **统计周期** | 本周 / 本月 / 上周 / 上月（均按触发时间） |
| **确认人** | 选一个平台用户（显示名（登录名）· 邮箱）。报告生成后，一次性确认链接会发到这个邮箱 |
| **收件人** | **至少 1 个**；可从列表选，也可直接输入邮箱后回车 |
| **启用** | 开关。停用后不再按 cron 产生新实例，已有实例不受影响 |

保存后，列表里能看到「下次执行时间」和「待确认」数量。

---

## 4. 等报告

- 到了时间系统自动生成 → 状态变「待确认」→ 系统给确认人发一封确认邮件（含一次性链接，**72 小时**有效）。
- 不想等：任务行点「**手动触发**」→ 立即生成一份，同样走确认流程。
- 24 小时还没确认，确认人会收到一次催办提醒。
- 看历史：任务行点「**执行记录**」→ 点某一行看详情（AI 摘要、事实数据、执行时间线）。

---

## 5. 确认报告（确认人收到邮件后）

打开邮件里的链接，依次做：

1. **看概要** —— 报告、统计周期、生成时间、收件人、「共 N 个指标，N 个异常（变化超过 10%）」、确认有效期。
2. **看内容** —— 点「**展开预览**」看 PDF（转 PDF 需要几十秒，会自动重试），或点「**下载 Word 版**」。
3. **填总结**（模板里带 `总结_xxx` 占位时才有）：
   - 点「**上传 Excel**」（仅 `.xlsx` / `.xlsm`，≤ 20MB）——系统按表格内容做分类统计；
     有多个总结占位时，**每个占位都要单独上传对应的文件**；
   - 填「**写作要求（可留空）**」——写清分类口径，如「按处理类型分类统计并列数数量」；
   - 点「**AI 生成总结**」→ 在「总结文本」框里直接改 → 点「**查看依据**」核对分类和行号。
4. **选一个动作**：
   - 「**确认并发送给收件人**」→ 报告立即发给收件人，附件 = Word 报告 + 你上传的原始 Excel。
   - 「**仅确认不发送**」→ 系统结束本轮任务，**不再发报告也不再催办**。适合你已经线下改好并发出去了的情况。
5. 确认链接**一次性**，确认完就不能再改；已发出的内容以确认那一刻的文本为准。
   （点一次就好，不要重复点 —— 重复提交会报「该链接已使用」。）

## 6. 状态速查

| 状态 | 含义 | 你能做什么 |
|---|---|---|
| 待生成 / 生成中 | 正在跑 | 等 |
| 待确认 | 已生成，等确认人确认 | 重新发送确认邮件、下载 |
| 部分成功 | 有变量本期没取到数，文中替换为 `NO_DATA` | **只能「仅确认不发送」**，不能直接发 |
| 已确认 / 已推送 | 已确认并发出 | 下载 |
| 已确认（未发送） | 确认了但系统没发 | 下载（终态，改不了） |
| 推送失败 | 邮件没发出去 | 重试推送 |
| 生成失败 | 生成出错 | 重新生成 |

---

## 7. 遇到问题怎么办

| 现象 | 怎么办 |
|---|---|
| **确认链接过期** | 任务创建人在「报告任务 → 执行记录」点「**重新发送确认邮件**」；确认人登录平台后也能直接确认 |
| 收不到确认邮件 | 先看「执行记录」里的执行时间线；仍没有就找管理员查「系统设置 → 推送记录」 |
| 报告里某段是 `NO_DATA` | 该指标本期没取到数（数据源或监控项问题），联系管理员，或换一个统计周期 |
| AI 摘要里的数字看着不对 | **以「事实数据」为准**；确认前可在报告详情里点该段「重新生成」 |
| 上传 Excel 报错 | 只支持 `.xlsx` / `.xlsm`、≤ 20MB；且模板里必须存在对应的 `总结_xxx` 占位 |
| 提示「模板名称已存在」 | 模板名全系统唯一，换个名字 |
| 别人已经处理过了 | 「已确认（未发送）」是终态，无法再改，需要管理员代确认 |
| 想改已经发出的报告 | 改不动了。确认时是**快照**；需要就请管理员重新生成一份 |

---

## 一句话记住

> 你只做两件事：**建任务** + **确认一次**。
> 其余全自动：定时触发 → 取数 → 算指标 → AI 写稿 → 套 Word → 转 PDF → 发确认邮件 → 催办 → 发给收件人 → 留痕。
