指标定义（计算变量）
配置「取数 + 聚合公式」，产出报告可引用的变量。变量不一定是数字——可以是标量、时序曲线或占比饼图，渲染时按类型生成数值或图表插入 Word。
+ 新增变量
变量 = 取数配置 + 聚合公式 + 产出类型。报告模板中的占位符绑定的是变量，而不是裸数字： scalar 标量 渲染为数值文本， timeseries 时序曲线 渲染为折线图， pie 占比 渲染为饼图。

变量产出预览（2026-09 期，计算引擎产出）

scalar cpu_usage_avg

62.4 % 环比 +3.1%

facts: { value: 62.4, baseline: 60.5, delta_pct: +3.1 }

timeseries net_traffic_trend

facts: { series: [{t, in, out}…], unit: "Mbps" }

pie storage_usage_pie

facts: { segments: [{label, pct}…] }

无论产出是数值还是图表，都属于 facts：只由计算引擎生成，AI 不可修改；渲染报告时图表变量生成图片嵌入 Word。

取数配置（query_config）

通过 Adapter 实时拉取可选范围，避免手填出错：

① 选主机组list_host_groups() → 「核心生产」「数据库」「网络设备」…
② 选监控项list_items(host_group_ids, value_types=[0,3]) → 只列数值型 item
③ 支持通配item_key_pattern: "vfs.fs.size[*,pused]" 批量匹配

聚合公式（calc_formula）

Adapter 透传小时级趋势的 min/avg/max 三列，计算引擎二次聚合：

{ "agg": "avg", "compare": "mom", "baseline_lookback": 1 }
本期区间2026-09-01 ～ 2026-09-30（UTC）
基线区间2026-08-01 ～ 2026-08-31（日历月平移）
scalar 产出value / baseline / delta_pct
timeseries 产出series[{t, value…}]（可叠加基线序列）→ 渲染折线图
pie 产出segments[{label, pct}] → 渲染饼图
